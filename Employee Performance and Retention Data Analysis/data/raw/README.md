# Raw Employee Data

`employees.csv` is a **synthetic educational sample** created so the analysis pipeline can run end-to-end.

The original `employees.csv` file was not committed to this repository. Column names and formats match what the scripts expect (`First Name`, `Gender`, `Senior Management`, `Team`, `Start Date`, `Last Login Time`, `Salary`, `Bonus %`), including missing values for cleaning exercises. Values are randomly generated (seeded) and are not real employee records.
